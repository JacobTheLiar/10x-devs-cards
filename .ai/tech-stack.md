Frontend - Angular z komponentami PrimeNG
- Angular 18 pozwala na szybkie budowanie aplikacji webowych
- W połączeniu ze stylami od PrimeNG (Tailwind) pozwoli na przyjazne dla oka doznania


Backend - Supabase jako kompleksowe rozwiązanie backendowe:
- Zapewnia bazę danych PostgreSQL
- Zapewnia SDK w wielu językach, które posłużą jako Backend-as-a-Service
- Jest rozwiązaniem open source, które można hostować lokalnie lub na własnym serwerze
- Posiada wbudowaną autentykację użytkowników


AI - Komunikacja z modelami LLM
- Dostęp do dowolnego modelu językowego uruchamianego na Ollama w obrazie Dockerowym
- Pozwala na nieograniczony dostęp dla mniejszych modeli
- Doskonałe rozwiązanie na potrzeby tego projektu
- Przykładowe modele Mistral 7B Instruct, Gemma 7B Instruct, Phi-3 Mini


CI/CD i Hosting:
- Github Actions do tworzenia pipeline'ów CI/CD
- Serwer VPS od CAL.pl do hostowania aplikacji za pośrednictwem obrazu docker
